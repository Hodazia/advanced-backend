But how to create a DB in mysql, there are sequelize commands, but go inside the /src/ folder 
`npx sequelize db:create` // it will create a DB in mysql with the DB name from src/config/config.json

EVERY TABLE IS CONSIDERED AS A MODEL, 
`npx sequelize model:generate --name Airplane --attributes modelNumber:string,capacity:integer ` 

// it will generate a model and add migrations to it, `--name ` it tells the sequelize what should be the 
table/model name is , `--attributes` it will define the columns, then without any space, u give its datatype 

OUTPUT will be something like this,
New model was created at C:\Users\ziaul\OneDrive\Desktop\backend_microservices\src\models\airplane.js .
New migration was created at C:\Users\ziaul\OneDrive\Desktop\backend_microservices\src\migrations\20250504145553-create-airplane.js .

it won't create a table file, but just create models in models folder, that's where migrations are used,
migrations is like git add, but not git commit, so what migrations file contain is what are the commits/changes that will happen once they are committed,
HOW TO COMMIT THE DB, use command - `npx sequelize db:migrate`, whatever be the pending migrations , commit all of those,
`OUTPUT` -> it will return two tables like 'Airplane' AND 'sequelizemeta'

Now if u want to revert back to the old migration, there is a command
`npx sequelize db:migrate:undo` , the airplane table will be gone
