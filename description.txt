ORM VS ODM
- ODM - no SQL DB

- ORM - SQL DB, object relational mapping, then we write somehting like CREATE TABLE table_name({}),
what it does u write a oop related code and internally it gets converted and interacts with db easily, 
We will be using sequelize , we can do data modelling in it, u can read the overall docs, 
`npm install sequelize`
So sequelize is an ORM for any relational DB, so how will sequelize know which DB to connect with, so for that we need drivers,
so we will be connecting to mysql driver,  to make a connection from the ORM layer to the DB layer,
`npm install mysql2`

there is something called as sequelize CLI, it gives u some commands which are the same for any DB drivers u use,
`npm install sequelize-cli`
then run `npx sequelize init` ->
